# Chem AI crush

**Ұраны:** «Атомнан молекулаға. Теориядан практикаға.»

Бұл архивте бастапқы HTML демо-нұсқасы брендке сәйкестендіріліп, бет атауы, іздеу жүйесіне арналған сипаттамасы және footer жаңартылған.

## Қалай ашуға болады
1. `index.html` файлын браузерде ашыңыз.
2. Бұл — бір файлдан тұратын фронтенд прототипі; Node.js міндетті емес.

## Қазіргі нұсқада бар
- Chem AI crush бренді және басты бет дизайны;
- бірнеше демонстрациялық химия тақырыбы мен қысқаша теория;
- демонстрациялық тест;
- алғашқы 20 элементке арналған периодтық кесте;
- молярлық масса калькуляторы;
- қарапайым арифметикалық калькулятор;
- адаптивті дизайн.

## Әзірге іске асырылмаған
Бұл файл өндірістік дайын толық платформа емес. Мыналар үшін бөлек серверлік және дерекқор жұмысы қажет:
- email арқылы тіркелу/кіру және құпиясөзді қалпына келтіру;
- қазақша/орысша толық локализация (қазіргі тіл ауыстырғышы демо туралы хабарлама көрсетеді);
- Supabase/PostgreSQL дерекқоры және RLS;
- оқушы мен мұғалім рөлдері, сыныптарды байланыстыру;
- серверде сақталатын ҰБТ тесттері, тест тарихы және прогресс;
- видео/кітап файлдарын жүктеу және сақтау;
- AI химик API интеграциясы;
- қауіпсіз тест сессиялары мен мұғалім статистикасы.

## Келесі техникалық қадам
Толық платформа үшін Next.js + TypeScript + Supabase архитектурасына көшу, SQL миграцияларын, RLS саясатын, авторизацияны және автоматтандырылған тесттерді қосу ұсынылады.

Құпия API кілттерін HTML немесе браузер кодына ешқашан жазбаңыз.
